# Kenneth R. Versola — Portfolio

Static portfolio website. No build step or framework is required.

## Deploy
Upload the entire folder contents to any static web host:
- cPanel / shared hosting
- Apache or Nginx
- GitHub Pages
- Cloudflare Pages
- Netlify
- Vercel static hosting

Open `index.html`.

The project screenshots are already included under `assets/`.
The Fuel Station Management System now includes 10 portfolio screenshots covering dashboard, fuel sales, expenses, financial reporting, inventory, dip readings, tanker trips, and remittance.

`Kenneth-Versola-Resume.doc` is included for the Download Resume button.
